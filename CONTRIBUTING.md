# Guía de Colaboración - UG-AI-Skills

¡Gracias por tu interés en contribuir al proyecto **UG-AI-Skills** de la Universidad de Guanajuato!

Este repositorio es una iniciativa comunitaria e institucional para garantizar que el uso de la Inteligencia Artificial en la UG sea ético, legal, transparente e identitariamente coherente.

## 🤝 ¿Cómo puedes contribuir?

1. **Proponer Mejoras Normativas**: Si identificas una actualización en la reglamentación universitaria (nuevos acuerdos de Rectoría General, reformas al Estatuto Académico, etc.), puedes actualizar o agregar reglas en las skills correspondientes.
2. **Añadir Nuevas Skills**: Si tu área requiere una skill especializada (ej. investigación, gestión presupuestal, tutorías), puedes proponer un nuevo módulo `.md` en la carpeta `skills/`.
3. **Corregir Errores o Erratas**: Si encuentras imprecisiones legales o técnicas, reporta un *Issue* o envía un *Pull Request*.

## 📋 Proceso de Pull Request (PR)

1. Haz un **Fork** de este repositorio.
2. Crea una rama descriptiva para tu contribución:
   ```bash
   git checkout -b feature/nueva-skill-investigacion
   ```
3. Realiza tus cambios asegurándote de fundamentar cualquier directiva legal en la reglamentación UG correspondiente.
4. Envía tu **Pull Request** utilizando la plantilla predeterminada y describe los cambios.
5. El equipo revisor analizará la propuesta para verificar su apego al marco jurídico universitario antes de fusionarla (*merge*).
